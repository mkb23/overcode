# Overcode 0.5.7 Release Notes

- **Dialogs match the command palette (#488).** Every dialog has the palette's frame, with the title and keys in the border, a highlighted row, choices shown with the current one lit, and a tip line explaining the highlighted row.
- **The column configurator is a guide to the columns (#490).** `C` lists every column with its header code, a live sample from the focused agent and what it means; the foot explains the highlighted one. It sits at the bottom of the screen so you can watch toggles land.
- **Dialogs re-centre when the terminal is resized.**
