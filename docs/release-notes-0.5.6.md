# Overcode 0.5.6 Release Notes

- **Sort by any column (#487).** Click a header to sort by it, click again to reverse; the sorted header shows ▼/▲. Child agents stay under their parent and the highlight follows the agent.
- **`S` is a sort picker.** It opens the palette on every sortable column plus Tree order; choosing the current sort reverses it. "Reverse sort" is also in the palette.
- **Column tooltips (#477).** Hover a header for what the column means; the `C` column configurator shows the same description for the highlighted column.
- **Command palette on `/` (#482).** One fuzzy picker for commands, agents (Ctrl+P) and tags (`T`), showing each command's key and current state.
